# Ferias y convocatorias (Encuentro)

Servicio adicional de la pestaña Encuentro, elegido por Jhon el 4 de noviembre de 2026. Igual que Beneficios suma descuentos y programas, Encuentro suma lugares reales para vender, mostrar el trabajo o conseguir un proyecto en Cali.

## Reglas
- Solo entra lo que se pudo leer en la fuente (página del organizador o de un medio). Cada fila guarda `fuente` y `verificado_en`.
- Lo que ya cerró (`cierre`) o ya pasó (`fecha`) se oculta solo. Si no hay nada vigente, la sección lo dice.
- Las ferias sin fecha publicada se muestran como "Por anunciar" y lo dicen en el detalle.
- Los miembros pueden sugerir una con "¿Sabes de una feria o convocatoria? Cuéntanos". Llega a `solicitudes_beneficio` con el nombre empezando por `[Convocatoria]`.
